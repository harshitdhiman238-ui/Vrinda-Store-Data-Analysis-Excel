# 📊 Vrinda Store Data Analysis using Microsoft Excel

## 📌 Project Overview

This project focuses on analyzing Vrinda Store's sales data using Microsoft Excel.

The project includes data analysis, pivot tables, charts, sales performance analysis, customer insights, order status analysis, state-wise sales analysis, gender analysis, and sales channel analysis.

The goal of this project is to convert raw sales data into meaningful business insights using Microsoft Excel.

---

## 🎯 Objectives

- Analyze overall sales and order performance
- Compare sales between men and women
- Analyze different order statuses
- Identify top-performing states
- Analyze customer age and gender
- Compare different sales channels
- Identify sales trends and patterns
- Create meaningful reports and visualizations
- Present business insights using Excel

## 📊 Analysis Performed

### 1. Sales vs Orders
Analyzed the relationship between sales amount and number of orders.

### 2. Product Analysis
Analyzed product-level performance and sales.

### 3. Men vs Women
Compared purchasing and sales performance between male and female customers.

### 4. Order Status
Analyzed delivered, cancelled, returned and other order statuses.

### 5. Top 5 States
Identified the top-performing states based on sales.

### 6. Age & Gender Analysis
Analyzed customer age groups and gender to understand purchasing behavior.

### 7. Sales Channels
Compared performance across different sales channels.
